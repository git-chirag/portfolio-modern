# Chirag Aparadh | Portfolio

A responsive personal portfolio focused on backend engineering, distributed
systems, cloud infrastructure, and applied AI.

For the content map, feature flags, and safe update instructions, see
[`WEBSITE_STRUCTURE.md`](./WEBSITE_STRUCTURE.md).

## Local development

```bash
npm install
npm run dev
```

The site is available at `http://localhost:3000` by default.

## Quality checks

```bash
npm test
npm run lint
npm run build
```

## Deployment

The project is configured for Vercel. Import the GitHub repository into Vercel;
the framework and build settings are detected automatically.

Keep the previous portfolio live until this deployment has been reviewed and
the production domain is intentionally moved or redirected.
